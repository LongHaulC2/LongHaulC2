# Operator Manual v2.0

## 1. Overview
The **LongHaul C2 Framework** is designed for high-latency, stealthy operations. This manual covers the deployment of agents, listener configuration, and post-exploitation modules.

> **WARNING:** Unauthorized use of this software is strictly prohibited. Ensure you have proper authorization before deployment.

## 2. Quick Start

To generate a new implant, navigate to the `Payloads` tab or use the CLI:

```bash
./longhaul build --os windows --arch x64 --listener http_1

```

## 3. Configuration Profiles

Malleable C2 profiles define the traffic indicators.

* **Get:** Defines the initial check-in.
* **Post:** Defines the data exfiltration path.

### Example Profile Block

```javascript
http-get {
    uri "/api/v1/status";
    client {
        header "User-Agent" "Mozilla/5.0 (Windows NT 10.0; Win64; x64)";
    }
}

```

## 4. Troubleshooting

If the agent fails to check in:

1. Verify the `BIND_HOST` is accessible.
2. Check firewall rules for port `80` or `443`.
3. Inspect the `server.log` for connection attempts.
